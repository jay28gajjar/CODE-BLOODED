# Web Security Shield

A Universal AI-Powered Web & Phishing Security Chrome Extension that provides real-time protection against malicious websites, phishing attempts, and dangerous links.

## Features

- **Real-time Link Analysis**: Hover over links to get instant security assessments.
- **Webpage Scanning**: Analyzes page structure for hidden threats, suspicious scripts, and fake forms.
- **Brand Impersonation Detection**: Uses Levenshtein distance and heuristic analysis to identify typosquatting and impersonation.
- **AI-Powered Threat Intelligence**: Optional integration with OpenAI, Gemini, or Anthropic for deep heuristic analysis.
- **Local Fallback**: Strong rules-based analysis that works completely offline.
- **Customizable Thresholds**: Set your own sensitivity levels for warnings.

## Architecture

```
User (Browser Tab)
       |
       v
Content Script <---> Hover Intent / DOM Analysis
       |
       v
Background Service Worker <---> Cache / Local Storage
       |
       v
Security Analysis Engine
  |-- Domain Utils (Typosquatting, TLD checks)
  |-- URL Utils (Redirect chains, Data URLs)
  |-- Heuristic Engine
  `-- External APIs (Google Safe Browsing, VirusTotal, AI Providers)
```

## Installation

1. Install dependencies:
   ```bash
   npm install
   ```

2. Build the extension:
   ```bash
   npm run build
   ```

3. Load into Chrome:
   - Go to `chrome://extensions/`
   - Enable "Developer mode" in the top right
   - Click "Load unpacked"
   - Select the `dist` folder generated by the build step

## Configuration

You can configure API keys and protection settings via the Extension Options page:
1. Right-click the extension icon
2. Select "Options"
3. Configure your API keys (Google Safe Browsing, VirusTotal, AI Providers)
4. Customize your protection settings and thresholds

## Supported Websites

Web Security Shield analyzes links universally across all websites. It has specialized enhanced parsing for major webmail providers including:
- Gmail
- Outlook/Live
- Yahoo Mail
- ProtonMail

## Risk Levels

- **LOW**: No obvious threats detected. URL and domain appear standard.
- **SUSPICIOUS**: Some heuristic flags triggered (e.g., suspicious TLD, multiple redirects, brand similarity).
- **HIGH**: Known malicious URL or very high confidence of phishing/malware based on structure or AI analysis.
- **UNKNOWN**: Could not be fully analyzed.

## Permissions

- `storage`: Used to cache analysis results and save your settings.
- `tabs`: Required to inject content scripts and check current page URLs.
- `scripting`: Needed to execute analysis scripts dynamically.
- `alarms`: Used for cache cleanup and periodic local database updates.
- `contextMenus`: Provides quick-scan options from the right-click menu.
- `notifications`: Alerts you of high-risk threats detected on the page.
- `<all_urls>` host permission: Necessary to analyze links and pages universally.

## Privacy Policy

This extension performs most analysis locally in your browser to protect your privacy.
- If AI analysis or external APIs are disabled, **NO** URLs or page content leave your browser.
- If enabled, only the URL (and optionally page HTML for AI analysis, if consented) is sent to the configured provider.
- Scan history is strictly stored locally in your browser and is opt-in.
