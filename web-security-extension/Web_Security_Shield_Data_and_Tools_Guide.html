Master Reference Manual

Web Security Shield

Complete Technical & Layman Breakdown of Every Tool, Language, Dataset, Algorithm & Rule

Manifest V3 Chrome Extension | 100% Local-First Defense | Zero-Lag Pre-Click Protection

📌 Executive Summary & Purpose

Web Security Shield monitors hyperlinks across the entire internet in real time. When you hover your mouse over a link on any webpage (Twitter, Gmail, Reddit, banking sites, forums), it performs an instant, 15-millisecond threat inspection before you click. This document explains every single technical tool and data piece used to build this system, alongside intuitive real-world analogies.

1. Development Languages & Frontend Frameworks

An architectural blueprint inspector who checks that every beam, electrical wire, and pipe fits together precisely before construction begins, ensuring the building never collapses.

3. Chrome Extension Architecture & APIs

Shadow DOM (attachShadow({ mode: 'open' })) CSS Isolation
Exact Location in Project
src/content/security-overlay.ts
Technical Duty
Encapsulates the hover security popup inside a private Shadow DOM root attached to document.body. Blocks host webpage CSS rules from distorting popup fonts or layouts, and keeps extension CSS from bleeding into the website.
Layman Terms Explanation
Websites have thousands of their own styling rules. Without Shadow DOM, a crazy website design could make our security popup invisible, sideways, or illegible. Shadow DOM places the popup in an isolated, soundproof glass box.
🎯 Real-World Analogy
A soundproof VIP booth in a noisy stadium: what happens outside cannot disturb you, and your conversation inside does not leak out.
MutationObserver & WeakSet Zero-Lag DOM Watcher
Exact Location in Project
src/content/link-detector.ts, src/content/email-detector.ts
Technical Duty
Watches the webpage DOM tree for newly inserted links (infinite scroll, AJAX). Uses a WeakSet to mark processed elements so elements are never re-scanned and are garbage-collected automatically when removed by the page.
Layman Terms Explanation
Instead of constantly scanning the entire webpage every second (which would make your computer sluggish and drain your laptop battery), the extension sleeps until a new link appears, tags it with invisible ink, and remembers it with zero memory waste.
🎯 Real-World Analogy
A motion-sensing security spotlight that only turns on when someone walks up to the porch, saving power the rest of the night.
chrome.storage.local & Two-Tier Cache Memory & Storage
Exact Location in Project
src/utils/storage.ts, src/security/reputation-cache.ts
Technical Duty
Provides two-tier caching: Tier 1 is an ultra-fast in-memory Map in RAM (500 items max); Tier 2 is disk storage via chrome.storage.local. Safe links stay cached for 30 minutes; dangerous links expire in 2 minutes.
Layman Terms Explanation
If you hover over the same link five times in a minute, the extension doesn't waste time re-checking it. It looks at its short-term memory note and instantly displays the cached answer in 0.1 milliseconds.
🎯 Real-World Analogy
A handy sticky note on your desk where you write down frequently dialed phone numbers so you don't have to look them up in the heavy telephone directory every time.

4. Datasets, Dictionaries & Security Rules

Protected Brand Database (BRAND_DATABASE) Security Dataset
Exact Location in Project
src/security/brand-detector.ts
Dataset Contents
28 global target organizations (Google, Microsoft, Apple, PayPal, Amazon, Facebook, Chase, Wells Fargo, IRS, USPS, FedEx, etc.) mapped to all their verified, legitimate official domains.
Layman Terms Explanation
Phishing sites try to trick you by putting 'microsoft' or 'paypal' in their web address. This dataset is our verified VIP guest list: if a site claims to be Microsoft but its real registered domain isn't on the official list, it gets flagged for impersonation.
🎯 Real-World Analogy
An airport passport control officer with a database of legitimate embassy credentials. Anyone presenting a fake or lookalike badge is detained immediately.
Levenshtein Distance Algorithm Mathematical Typosquatting Matcher
Exact Location in Project
src/utils/domain-utils.ts
Technical Duty
Computes the edit distance between a hovered domain and protected brand names. Detects lookalikes like 'paypa1.com', 'micros0ft.com', and 'app1e.com' with similarity >= 0.7.
Layman Terms Explanation
Scammers replace letters with similar-looking numbers (like '1' instead of 'l'). Our mathematical formula measures the exact visual and character distance, instantly spotting deliberate misspellings.
🎯 Real-World Analogy
A counterfeit currency scanner at a bank that detects if a 100-dollar bill has a microscopic typo in the treasury secretary's signature.
Dangerous Schemes & Protocol Blacklist Rule Set
Exact Location in Project
src/types/url.ts, src/security/url-analyzer.ts
Dataset Contents
javascript: data: vbscript: file:
Layman Terms Explanation
Real web links start with https://. If a link starts with javascript: or data:, clicking it runs executable computer code right inside your browser. We immediately assign these a maximum threat score of 100/100.
🎯 Real-World Analogy
A postal package with no return address that has a lit fuse sticking out of the cardboard box. The bomb squad immediately marks it as maximum danger.

5. Multi-Factor Risk Scoring Matrix

Detected Indicator Score Weight Technical Reason & Layman Meaning
Dangerous Protocol (javascript:, data:) +100 Executable code scheme masquerading as a hyperlink. Immediate hazard.
Confirmed Threat Intel Hit +100 Verified malicious by Google Safe Browsing or VirusTotal scanner database.
Credential Form on Mismatched Domain +40 Website asks for passwords/cards while domain does not match the official brand.
Brand Impersonation / Typosquatting +35 Domain closely resembles a protected brand (e.g. google-security-login.com).
Cross-Domain Open Redirect +25 URL uses parameters like ?target= to secretly bounce you to an external site.
IP Address Destination +25 Uses raw IP numbers (e.g. 192.168.1.1) to avoid domain registration checks.
Punycode Homograph Spoofing (xn--) +20 Uses Cyrillic/Greek alphabets to visually imitate English domain letters.
Suspicious Top-Level Domain (.xyz, .tk) +15 Uses domain endings with high historical rates of cybercrime and abuse.
Login / Verification Path Keyword +10 Path contains /login or /verify. Contributes to risk only alongside other flags.
URL Shortener Masking (bit.ly, t.co) +10 Conceals true destination. Classified as UNKNOWN so users exercise caution.
Urgency / Coercive Language +10 Page text shouts 'Account suspended within 24 hours!' to induce panic.

🛡️ Privacy Guarantee

Zero Sensitive Data Stored: Web Security Shield only checks whether password or payment fields exist on a page. It never captures, reads, logs, or transmits your actual passwords, PINs, OTP codes, or credit card numbers. All core analysis runs 100% locally on your computer.
